# Project Survivors

## Caracteristicas de los NPCs

Como aclaracion inicial los npcs comparten similitudes con el personaje jugable: atributos y rasgos.

- Pertenencia a una comunidad: 
    Todos los npcs pertenecen a una comunidad, esto les permite agruparse y colaborar entre ellos o con el jugador. 

- Ejecutan ordenes [**_Modeable_**]:
    En todas las comunidades ejecutar ordenes. Si pertenecen a la comunidad del jugador es el jugador quien les da ordenes, sino un manager de comunidades. Las ordenes pueden ser salir a buscar comida, limpiar una zona de zombies, etc.

- Asignacion de tareas [**_Modeable_**]:
    Es una caracteristica relacionada con la anterior. A los npcs se les puede asignar tareas programadas que van a hacer que ejecuten cierta orden con frecuencia. 
        _Ejemplo_: Mantenerse en cierta zona patrullando, quedar apostado en una entrada del edificio que usa la comunidad como base, ocuparse de cultivos de comida.
