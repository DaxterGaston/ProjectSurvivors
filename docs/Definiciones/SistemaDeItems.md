# Project Survivors

## Caracteristicas del sistema de Items e Inventario

El sistema de items incluye 3 tipos de items: 

- ### Items clave: 
    Son objetos escenciales en la historia/subtrama. No se pueden destruir, tampoco construir por [metodos convencionales](/docs/Definiciones/SistemaDeConstruccion.md#items). Necesitan de algun npc o mesa de trabajo especifica de una mision para interactuar con ellos.
