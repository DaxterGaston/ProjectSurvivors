# Project Survivors

## Caracteristicas del sistema de Construccion

El sistema de construccion se compone de 2 sub-sistemas:

- ### Items:
    El jugador puede construir objetos que puede utilizar/equipar con materiales que tenga en el inventario. _Ejemplo_: Obtiene tela infectada de la ropa de los zombies, la desinfecta con agua hirviendo y luego la utiliza para construir una armadura ropa extra para obtener mas defensa. 
    Ciertos items requieren de una mesa especial de construccion para su confeccion.

- ### Estructuras:
    Se construyen estructuras para poder crear una base, o reforzar un edificio ya existente. Tambien hay construcciones que no son 100% estructurales, son muebles/contenedores como cajas para guardar objetos, camas para que descanse el jugador o los npcs, etc.
